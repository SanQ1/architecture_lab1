Назва: Створення замовлення
    Актор: Клієнт
    Передумови: Користувач автентифікований, замовлення не пусте.
    Основний сценарій:
        Користувач натискає "Створити замовлення".
        Система перевіряє чи не є замовлення пустим.
        Система створює замовлення.
    Альтернативні сценарії/помилки:
        Замовлення пусте: помилка.
        Користувача не існує: помилка 409.

Назва: Оплата замовлення
    Актор: Клієнт
    Передумови: Замовлення існує, користувач автентифікований.
    Основний сценарій:
        Клієнт створює замовлення.
        Клієнт натискає "Оплатити замовлення".

    Альтернативні сценарії/помилки:
        Клієнта не існує: помилка 409.
        Замовлення не існує: помилка 404.
        Коштів на рахунку не вистачає: помилка.

Назва: Авторизація
    Актор: Клієнт/Адміністратор
    Основний сценарій:
